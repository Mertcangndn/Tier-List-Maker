# Tier List Maker 🏆

A fast, lightweight, and privacy-friendly Tier List Maker built entirely on the client-side. No databases, no server uploads—just pure frontend magic. Created seamlessly through **vibe-coding**! ✨

## 🚀 Features

- **Fully Local & Private:** Images are converted to Base64 via the File API and stay completely in your browser. Zero server data transfer.
- **Drag & Drop:** Smooth sorting, swapping, and positioning powered by [SortableJS](https://github.com/SortableJS/Sortable).
- **Export as Image:** Download your finished tier list as a crisp, high-resolution PNG using [html2canvas](https://html2canvas.hertzen.com/).
- **Save & Load Projects:** Save your layout, tiers, and image pool as a `.json` file to pick up right where you left off.
- **Customizable Tiers:** Add new tiers, delete them, or change their colors on the fly.
- **Bilingual:** Built-in English and Turkish UI support.

## 🛠️ Built With

- **HTML5 & CSS3** (Custom UI, Flexbox layout)
- **Vanilla JavaScript** (DOM manipulation, File handling)
- **SortableJS** (Drag & Drop mechanics)
- **html2canvas** (Canvas rendering)
- **Vibe-coding** 🤖 (Developed via rapid AI-assisted natural language prompting)

## 💻 Getting Started

Since this is a fully static project, there is no build step, backend setup, or package manager required. 

1. Clone the repository:
   ```bash
   git clone [https://github.com/Mertcangndn/tier-list-maker.git](https://github.com/Mertcangndn/tier-list-maker.git)
   ```
   Open index.html in any modern web browser.

Start ranking your favorite things!
